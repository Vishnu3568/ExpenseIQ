# Screenshots Checklist & Visual Asset Map - ExpenseIQ

To prepare ExpenseIQ for GitHub and presentation, this document outlines the directory structure for static assets, a checklist of screens to capture, and recommended filenames.

---

## 📁 Visual Assets Directory Layout

All visual assets must be stored in the root `assets/` folder, organized by visual category:

```text
assets/
├── branding/          # Logo variations, icons, banners
├── screens/           # Main UI full-screen captures
└── demo/              # Animated GIFs showing features
```

---

## 📸 Screenshots Checklist & Recommended Filenames

For professional presentation, capture screenshots in high-resolution (1920x1080) with a modern dark/light system preference.
